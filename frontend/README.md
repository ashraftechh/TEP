# Frontend — Training Ecosystem Platform

React + TypeScript + Vite public SPA for the Training Ecosystem Platform.

Full setup instructions, architecture, and contribution guidelines live in the repository root — see [`../README.md`](../README.md) and [`../CONTRIBUTING.md`](../CONTRIBUTING.md).

## Quick reference

```bash
npm install
cp .env.example .env
npm run dev
```

Run tests:

```bash
npx vitest run
```

Lint/format:

```bash
npx eslint .
npx prettier --check .
```
